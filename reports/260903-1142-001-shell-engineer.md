# 260903-1142-001 — auto-close-settled-agent-tabs — shell-engineer report

## What changed

- **New:** `scripts/agent-cleanup.sh <event-id>` — the only path that closes a specialist's Herdr
  tab automatically. It requires the named event to be type `agent-done` and already present in
  `event-acks.jsonl` (never triggers on detection, emission, unread listing, or drain alone), then
  under the task's state lock re-reads current `.meta` and closes only if agent name, tab, session,
  and generation still equal the identity frozen into the event. Any mismatch is a safe no-op that
  reports the recorded vs. current generation/tab and leaves the replacement untouched. Reuses
  `close_recorded_tab()` for the actual close, so cleanup ends in the same `stopped=1` terminal
  state as a manual `agent-stop.sh`. A close failure `die`s before mutating meta — acknowledgement
  and metadata stay intact, exit is non-zero, and re-running the same command retries safely.
- **`scripts/herdr-runtime-lib.sh`:** extracted `close_recorded_tab(id, meta)` (Herdr tab close +
  `stopped=1` mark) out of `agent-stop.sh`, so both callers share one implementation and terminal
  state. Caller must already hold the task's state lock.
- **`scripts/agent-stop.sh`:** now calls `close_recorded_tab`; behavior unchanged (verified by the
  existing `tests/herdr-runtime.test.sh` coverage, unmodified).
- **`scripts/harness-event-lib.sh`:** `event_emit` gains an optional 5th `identity` JSON arg
  (default `{}`), stored as the event's new `identity` field. Purely additive — `event_id`/dedup
  semantics (task+type+generation) and every existing 4-arg caller, including `inbox.sh emit`'s
  CLI, are unchanged.
- **`scripts/events-poll.sh`:** on observing a `done` transition, reads the task's current `.meta`
  (agent_name, tab, session, generation) and passes it as `identity` on the `agent-done` event —
  resolved once, at the moment the transition is observed, not re-derived later. Other event types
  are unaffected.
- **Docs:** `docs/herdr-runtime.md` (commands list + full "Behaviour" contract),
  `docs/inbox-and-decisions.md` (ack → cleanup link), `agents/orchestrator.md` (operator guidance:
  use `agent-cleanup.sh` after acknowledging a done event instead of `agent-stop.sh`).
- **Plan card** updated in place with the resolved decision, an implementation summary, and an
  `## Owns` line.
