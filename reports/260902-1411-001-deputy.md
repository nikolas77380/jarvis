  starting point to fix, not a baseline to preserve unchanged.

  Since the shared harness must not depend on Yavo, replaced that mechanism with inline universal
  criteria plus stack-conditional bundle-size/server-runtime checks, rather than inventing new global
  skill files not requested by the task card.
- Next.js roles generalize the "yavo-admin has no git repo" case into a brief-driven branch rather
  than assuming every project has one, since that was a real (not hypothetical) shape in the source
  material worth preserving generically.
