# Harness memory

Verified rules that apply across managed repositories.

- A recorded lock/worktree is a live claim until exact runtime evidence proves otherwise. Evidence:
  [feedback_locked_worktree_is_live.md](feedback_locked_worktree_is_live.md).
- Execute claimed guarantees; comments and reports are not verification. Evidence:
  [feedback_verify_claims_by_execution.md](feedback_verify_claims_by_execution.md).
- Keep ad-hoc measurements local; record durable conclusions and methodology, not raw dumps. Evidence:
  [feedback_no_adhoc_reports_in_git.md](feedback_no_adhoc_reports_in_git.md).
- Confirm a named tool exists before putting it in a brief. Evidence:
  [project_reportfindings_tool_absent.md](project_reportfindings_tool_absent.md).
