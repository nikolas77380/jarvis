# Captain memory

Only explicit, durable preferences of the captain belong here.

- Ask for approval before every merge; approval never carries over to another PR. Evidence:
  [feedback_ask_before_every_merge.md](feedback_ask_before_every_merge.md).
- When the captain frames work as discussion, inspect and recommend before dispatching implementation.
  Evidence: [feedback_discuss_before_delegating.md](feedback_discuss_before_delegating.md).
- For UI work, provide a preview before requesting merge approval. Evidence:
  [feedback_preview_before_merge.md](feedback_preview_before_merge.md).
- Do not let completed task worktrees accumulate; identify live work before cleanup. Evidence:
  [feedback_worktrees_must_be_removed_after_work.md](feedback_worktrees_must_be_removed_after_work.md).
